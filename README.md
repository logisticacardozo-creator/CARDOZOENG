# Relatório de Caminhonetes — Cardozo Engenharia

Site estático para relatórios de manutenção de caminhonetes.

## Como usar

1. Clique em **Gerenciar frota** e cadastre as relações entre Tag e Placa.
2. No relatório, informe a Tag: a Placa é preenchida automaticamente.
3. Escolha a prioridade e o tipo de serviço, descreva o problema e salve.

Os cadastros e relatórios são armazenados localmente no navegador utilizado. Para uma equipe compartilhar os mesmos registros, será necessário conectar o site a um banco de dados ou planilha corporativa.

## Publicação no GitHub Pages

Envie estes arquivos para a raiz de um repositório GitHub e habilite **Settings > Pages > Deploy from a branch > main / (root)**.
